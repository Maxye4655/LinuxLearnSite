# PT203 Interactive Educational Website Template

This repository is a minimal starting point for the PT203 interactive educational website assessment.

## Folder structure

- `index.html` — the website homepage
- `css/style.css` — website styling
- `js/script.js` — interactive JavaScript functionality
- `images/` — images created or selected for the website
- `pages/` — additional HTML pages, if required

## Getting started

1. Open the repository folder in Visual Studio Code.
2. Open `index.html` using Live Server or Live Preview.
3. Build the website from your own design and planning.
4. Add additional pages, images, CSS and JavaScript as required.
5. Commit changes regularly using meaningful commit messages.

## Important

This template intentionally does not include a completed layout, navigation system, responsive design, educational activities, quizzes, scoring, feedback systems or other interactive features.

These features must be designed and developed by the student as part of the assessment.
